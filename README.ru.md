# 🦠 virus-evo-simulation

**virus-evo-simulation** — это визуальная симуляция распространения вируса с поддержкой мутаций, написанная на C с использованием SDL2. Проект моделирует поведение вирусных штаммов в клеточной среде: заражение, смерть, воскрешение, мутации. Симуляция запускается в реальном времени с графическим интерфейсом и использованием многопоточности.

## ⚙️ Особенности

- Симуляция клеточного автомата (здоровые / заражённые / мёртвые клетки)
- Случайные мутации вирусных штаммов с визуальным эффектом
- Воскрешение мёртвых клеток здоровыми
- До 10 штаммов одновременно на карте
- История мутаций с сообщениями
- Графический рендеринг через SDL2
- Многопоточность с защитой доступа к общим данным через `pthread_mutex_t`

## 🔧 Сборка

Для сборки требуется установленный **SDL2** и **SDL2_ttf**.

## 🛠️ Сборка и запуск (Linux)

Установите зависимости (пример для Debian/Ubuntu):

```bash
sudo apt install libsdl2-dev libsdl2-ttf-dev build-essential
```

Сборка проекта

```bash
make
```

После сборки в директории появится исполняемый файл:

```bash
./virus_sim
```

Очистка

```bash
make clean
```

## 📁 Логика симуляции
* Каждая клетка может находиться в трёх состояниях: здоровая, заражённая, мёртвая
* Заражённая клетка может умереть или выздороветь, в зависимости от свойств штамма
* Мёртвые клетки могут быть "воскрешены" с определённой вероятностью
* Каждый штамм имеет:
  * Цвет
  * Шансы заражения, смерти, воскрешения
  * Время восстановления
* При мутации создаётся новый штамм с модифицированными свойствами и другим цветом
* Мутации отображаются визуально и сохраняются в историю

## 🧵 Потоки
Проект использует потоки (pthread) для разделения симуляции и отрисовки, обеспечивая плавную визуализацию без блокировки основной логики.
